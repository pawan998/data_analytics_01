# Data Analytics - Loan and Payment Analysis

## Overview
This project performs exploratory data analysis (EDA) on loan and payment data to uncover insights and patterns related to lending activities.

## Project Structure
- `data_analysis_v01.ipynb` - Main Jupyter notebook containing data analysis workflows
- `data/input/` - Input data files:
  - `loan.csv` - Loan records (577,682 rows, 19 columns)
  - `payment.csv` - Payment records (689,364 rows, 9 columns)
  - `clarity_underwriting_variables.csv` - Variable descriptions and metadata (49,752 rows, 54 columns)
- `data/output/` - Output directory for analysis results

## Analysis Steps
1. Data Loading - Imports loan, payment, and variable metadata files
2. Data Exploration - Examines structure and content of datasets
3. Data Merging - Combines loan and payment data for comprehensive analysis
4. EDA (Exploratory Data Analysis) - Analyzes patterns, distributions, and relationships

## Requirements
- Python 3.12.4
- Pandas
- Jupyter Notebook

## Getting Started
Open `data_analysis_v01.ipynb` in Jupyter Notebook to run the analysis.
